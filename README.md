## My Favorite Movie

**Toy Story**

*Genre: Animation / Comedy / Adventure*

### Why I like it

- I like how the story shows toys that come alive when no one is looking.
- I like the friendship between Woody and Buzz, because they start as rivals and become best friends.
- I like it because it is funny and touching at the same time, and it makes me feel like a kid again.

### Favorite Scene

> The scene where Woody and Buzz work together to get back to Andy. It shows that real friends help each other even when things are hard.
